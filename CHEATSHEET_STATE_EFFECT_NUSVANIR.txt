# 📜 MASTER CHEATSHEET: STATUS EFFECTS (STATES)
Proyek Game: Tales of The Dark Time  
Engine: RPG Maker MV  
File Database: data/States.json

================================================================================
📌 CATATAN PENTING & RENCANA INTEGRASI PLUGIN YANFLY
================================================================================
Seluruh state di bawah ini telah dikonfigurasi pada database default RPG Maker MV.
Namun, untuk beberapa state yang memiliki mekanik kondisi dinamis (misal: peluang 10%
gagal aksi tiap turn, lepas saat menyerang, kombo reaksi elemen), disediakan
[YANFLY NOTE TAG] (YEP - Buffs & States Core) di setiap rincian state.

Saat plugin Yanfly diinstal nanti, Anda cukup menyalin kode di bagian [YANFLY NOTE TAG]
ke dalam kotak Note masing-masing State di database RPG Maker MV agar perilakunya
100% presisi sesuai desain mekanik Anda!
